# Инструкции для Antigravity CLI

## О проекте
- Java-мод для Mindustry v8, хук в SchematicsDialog через рефлексию

## Источники информации
- Mindustry core repo: https://github.com/Anuken/Mindustry
- Mindustry wiki: https://mindustrygame.github.io/wiki/

## Конец выполнения запроса
- Обязательно перепроверяй себя
- Перед формированием финального отчёта пользователю обязательно запусти `./gradlew mjar` и убедись, что сборка прошла без ошибок
- Пиши отчет о выполненной задаче

## Команды и права
- Все команды начинающиеся на `./gradlew` разрешены, для остальных запрашивай подтверждение
